# agentic-hitl-medical-annotation
An agentic human-in-the-loop framework for medical text annotation, combining an LLM-based annotator, a feedback agent for iterative prompt refinement, and human expert review to improve annotation quality on high-stakes clinical data.


## Dataset

This project uses the **Medical Text Dataset** from Kaggle.

- Source: https://www.kaggle.com/datasets/chaitanyakck/medical-text
- Files used: `train.dat`, `test.dat`

Due to dataset licensing, the data is **not included** in this repository.
